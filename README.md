# Credit Risk Prediction Using Machine Learning

## 📌 Overview
This project predicts loan default risk using machine learning techniques such as Logistic Regression, Random Forest, and XGBoost.

## 📁 Project Structure
- credit_risk_model.ipynb — Full ML code
- dataset/credit_data.csv — Training dataset
- src/ — Python helper scripts
- images/ — Visualizations
- project_proposal.docx — Complete project proposal

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Google Colab
- GitHub

## 📊 Model Performance
- Accuracy: 92%
- Precision: 0.89
- Recall: 0.90
